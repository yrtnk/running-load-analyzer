PR $ARGUMENTS をレビューします。

## 確認すること
1. `gh pr view $ARGUMENTS` で PR の概要を確認する
2. `gh pr diff $ARGUMENTS` で変更内容を確認する
3. 対応する Issue の完了条件を `gh issue view <Issue番号>` で確認する

## レビュー観点（この順番でチェック）
1. **MVPスコープ** — 不要な機能が追加されていないか
2. **完了条件** — Issue に書かれた完了条件をすべて満たしているか
3. **Service Object** — ロジックがコントローラに書かれていないか
4. **N+1** — クエリの N+1 が発生していないか
5. **テスト** — RSpec が含まれているか

### 総評
（マージ可能か、修正が必要かを一言で）
