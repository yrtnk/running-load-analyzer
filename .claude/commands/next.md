今日の開発状況を確認して、次にやるべきことを教えてください。

## 確認すること
1. `gh pr list` でレビュー待ちの PR があるか確認する
2. `gh issue list --label ready-for-claude` で今すぐ着手できる Issue を確認する
3. 直近のコミット履歴（`git log --oneline -5`）を確認する

## 出力フォーマット
以下の形式で簡潔に報告する：

### レビュー待ち PR
（あれば PR 番号・タイトルを列挙）

### 今すぐ着手できる Issue（ready-for-claude）
（Issue 番号・タイトルを列挙）

### 推奨アクション
「今日は Issue #__ を実装するのがおすすめです。理由：__」
（依存関係・Milestone の締切を考慮して1つだけ推薦する）
